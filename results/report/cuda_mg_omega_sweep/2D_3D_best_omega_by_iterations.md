# 2D and 3D CUDA MG omega sweep: best omega by iterations (V/W split)

這份報告整理 `results/report/cuda_mg_omega_sweep` 內 2D 和 3D sweep 的結果，並將統計分成 `V` / `W` 兩個 cycle。

## Scope

- 資料來源：`2D_*_*/results_all.csv` 與 `3D_*_*/results_all.csv`
- `omega` 掃描範圍：`1.00` 到 `1.50`，步長 `0.05`
- 對象：2D 和 3D 的所有 `case`
- 統計方式：`V-exact` + `V-SOR` 合併為 `V-cycle`，`W-exact` + `W-SOR` 合併為 `W-cycle`
- 結果判定：只計算 `converged = true` 的樣本平均 `iterations`
- 選擇規則：對每個 `grid + nu + cycle + omega` 計算平均 `iterations`，取最小者；若平手則取較小的 `omega`
- 每個 `grid + nu + cycle + omega` 共有 10 個樣本（5 cases × 2 coarse solves）
- 註：這組 sweep 的 `max_iter = 15`，所以大 grid 可能因為迭代上限而無法全部收斂

## Overall summary

如果只看 2D + 3D 全部收斂樣本：

| cycle | best omega | mean iterations |
|---|---:|---:|
| V | 1.25 | 6.867 |
| W | 1.15 | 5.159 |

整體來看，`W-cycle` 偏向較小的 `omega`，而 `V-cycle` 的最佳值通常會往 `1.20 ~ 1.30` 移動。

## Notes

- `V-cycle` 和 `W-cycle` 的最佳 `omega` 不同，不建議把兩者混成同一個預設值。
- 2D 的高 grid 在 `max_iter = 15` 下已經開始受限，所以 `4095+` 的最佳 `omega` 比較適合當參考值。
- 3D 裡 `V-cycle` 會隨 `nu` 增加而偏向更大的 `omega`；`W-cycle` 則大多維持在 `1.15 ~ 1.25`。
